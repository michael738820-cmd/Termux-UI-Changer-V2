# Termux UI Changer V2

A safer, feature-rich terminal customization utility for Termux.

## Features
- 8 built-in themes
- Automatic and manual backups with restore
- Environment diagnostics
- Update checks without silent self-updates
- Safe, managed shell prompt and MOTD customization

## Installation
```bash
git clone https://github.com/michael738820-cmd/Termux-UI-Changer-V2.git
cd Termux-UI-Changer-V2
python termux_ui.py
```

See [Instructions.md](Instructions.md) for details.

## Tests
```bash
python -m unittest discover -s tests -v
```
